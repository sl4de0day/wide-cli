# Security Policy

## Supported Versions

Security updates apply to the latest release version published on `main` and npm (`wide-cli`).

## Reporting a Vulnerability

If you discover a security vulnerability in Wide CLI (such as command injection, workspace path traversal, secret masking bypass, or remote bundle checksum bypass):

1. Open a private GitHub Security Advisory at https://github.com/sl4de0day/wide-cli/security/advisories/new.
2. Provide reproduction steps, CLI flags or configuration, and a minimal test payload.
3. Wait for a patched release before public disclosure.
